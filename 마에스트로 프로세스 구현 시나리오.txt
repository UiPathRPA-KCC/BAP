#시나리오1: 기본 틀 잡기
Campaign Creator 프로세스클 그리고 싶어. 아래 단계클 참고해줘. 
시장 분석 -> 콘텐츠 생성 -> 캠페인 실행 -> 리드 관리 -> 성과 분석 -> 전략 수정.
 대기업의 대규모 마케팅 행사를 진행한다고 가정하고, 각 단 계는 사람이 (AI ×) 진행하는 것으로 가정하여, 태스크의 상세 내용과 평 균 리드타임을 어노테이션에 작성해줘. 전부 한글로 작성해줘.

#시나리오3: AI 태스크로 전환
각 태스크클 사람이 아닌 AI 자동화 태스크로 변경해줘. 
그리고, 시장 분석, 콘텐츠 생성 단계에 사람이 검토하고 승인하는 단계클 넣어줘. 승인 이 반려될 경우 다시 수정하는 흐름(거절 경로)도 추가해줘

#시나리오4: 에이전트 구체화
콘텐츠 생성 태스크클 담당할 Agent를 만들고 싶어. 아까 추천해준LLM으로 구동되는 Agent 프로젝트클 만들어줘.

#시나리오5: 에이전트 수정1
이 Agent에 GPT-4o 기반 콘텐츠 생성 워크플로우를 구성해줘

#시나리오6: 에이전트 수정2
마케팅 캠페인을 10개정도 작성한 뒤, 생성된 콘텐츠의 톤앤매너 및 느랜드 쿨을 준수하면서 가장 효과가 좋을 것으로 예상되는 캠페인 탑3개 만 선정해서 사람이 검토할 수 있도록 메일로 보내주면 좋을 것 같아.

#시나리오7: 에이전트 이메일 연동
Send Email 도구를 직접 추가했어. 이제 프롬프트를 업데이트해줘

#시나리오8: 에이전트 검증
테스트클 하기 전에, Agent 전체클 한번 점검 해줘. 입력/출력 파라미터 는 이상 없는지, 프롬프트에 오류는 없는지, 프롬프트클 실행했을 때 올 바른 결과가 나올 수 있을지 등등. 총 세 번 점검 해줘.
